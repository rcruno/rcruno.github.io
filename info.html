This is my infographic project. In this project we were taught by our professor how to use indesign to create an interesting infographic for a communication system. Here we learned what an infographic is and basic design principles that make the infographic presentable. After being designed in the software it is then printed out on 11x17 paper where it is inducted to a class contest.
